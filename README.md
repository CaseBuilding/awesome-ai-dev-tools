## 🤖 关于本项目

本合集由 [GitHub Actions](#) 每周自动更新。

**维护方式：**

1. 自动分类不准 → 编辑 `data/manual_overrides.json` 手动修正

3. 想调整搜索范围 → 编辑 `config/search-queries.json`
