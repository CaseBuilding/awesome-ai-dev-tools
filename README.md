## 🤖 关于本项目

由 GitHub Actions 每周自动更新。人工修正请编辑：

- 修正分类 → `data/manual_overrides.json`
- 关注项目 → `data/watched.json`
- 调整搜索 → `config/search-queries.json`
- 调整规则 → `config/categories.json`

更多说明见 [docs/REQUIREMENTS.md](docs/REQUIREMENTS.md)
