## 🤖 关于本项目

本合集由 [GitHub Actions](https://github.com/affaan-m/ECC) 每周自动更新。

**维护方式：**

1. 自动分类不准 → 编辑 `data/manual_overrides.json` 手动修正
2. 想调整分类规则 → 编辑 `config/categories.json`
3. 想调整搜索范围 → 编辑 `config/search-queries.json`

更多说明见 [docs/REQUIREMENTS.md](docs/REQUIREMENTS.md)
